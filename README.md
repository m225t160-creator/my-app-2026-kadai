# 📝 Classroom Memo

授業中にサッとメモを取り、Markdownで整理できる、GitHub Pages対応のスタイリッシュなメモアプリです。

## ✨ 特徴

- **Markdown対応**: リアルタイムプレビューで、見やすいノートが作成できます。
- **ドラッグ＆ドロップ**: メモの順番を自由に入れ替えられます。
- **LocalStorage保存**: 面倒な保存ボタンは不要。ブラウザに自動で保存されます。
- **検索機能**: タイトルや内容から、過去のメモを瞬時に検索できます。
- **レスポンシブデザイン**: PCはもちろん、タブレットやスマートフォンでも快適に使えます。

## 🚀 使い方

### 1. メモを作成する
右上の「**新規メモ**」ボタンをクリックすると、エディタが開きます。
タイトルと内容を入力してください。

### 2. Markdownで記述する
左側の入力欄（編集エリア）にMarkdown記法で入力すると、右側にプレビューが表示されます。
- `# 見出し` で見出し作成
- `- リスト` で箇条書き
- `**太字**` で強調
- `` `コード` `` でコードブロック

### 3. メモを並び替える
メモ一覧のカードをドラッグして、好きな位置に移動させることで順番を変更できます。

### 4. メモを検索する
ヘッダーにある検索バーに文字を入力すると、タイトルまたは内容にその文字が含まれるメモだけが表示されます。

### 5. メモを削除する
メモカードの右上にあるゴミ箱アイコンをクリックすると、削除の確認が表示されます。

## 🛠 公開方法 (GitHub Pages)

このアプリを自分のURLで公開するには、以下の手順を行ってください：

1. GitHubリポジトリの **Settings** タブをクリックします。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** セクションで、Branchが `main` になっていることを確認し、**Save** をクリックします。
4. 数分待つと、上部に公開URL（`https://<username>.github.io/<repo-name>/`）が表示されます。
